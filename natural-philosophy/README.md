# Natural Philosophy archive

This standalone section preserves material from `myndworkz/my-website`:
`what-is-it.html`, `history-philosophy.html`, `events.html` and
`Archive/static_site/philosophy_workshops.html`. Event information is
historical and should be checked with the venues.

Open `index.html` in a browser to preview the archive. Alternatively, serve
the repository root with `python -m http.server 8000` and visit
`http://localhost:8000/natural-philosophy/`.
